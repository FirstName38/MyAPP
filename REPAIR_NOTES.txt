Luma enhanced v4

Implemented in this project:
- Standard / ADHD / Custom / Stopwatch focus modes.
- Focus -> Short Break -> Focus -> Long-cycle-ready architecture.
- Start / Pause / Resume / Finish / Focus-Break controls.
- Per-pause start/end/duration, total paused time and active time persisted.
- Continuous looping focus/break sounds.
- Separate focus, break and alarm sound categories.
- Task dates, priorities, labels, descriptions and linked focus-session history.
- Habit descriptions, labels, duration and day-by-day percentage completion.
- Calendar day overview with tasks, habits, journal and focus data.
- AI analysis screen with Anthropic API key/model settings.
- Accessibility and usage-access settings shortcuts.
- Camera permission and local preview in Focus Room.
- Animation on/off setting.
- Clock screen: countdown timer, stopwatch and alarm.
- More aesthetic wallpapers.

Important limitations:
- True multi-user Focus Room/video calling requires a backend/signaling/WebRTC service and is not falsely represented as implemented.
- Online sound search/streaming is not bundled because it requires a source/service and licensing; local device sound selection can be added without changing the timer architecture.
- Build must be verified in Android/Gradle environment or GitHub Actions.
