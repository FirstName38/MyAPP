# Luma — personal focus & productivity companion

This build turns the existing Luma foundation into a more usable Android productivity app.

## Included
- Focus stopwatch, Standard, ADHD and Custom modes.
- Before every focus session: **choose what you are doing** from saved tasks or choose Other.
- Focus wallpapers: Nebula, Ocean, Sunset, Midnight, Forest, Aurora, Dream and Paper.
- Bundled focus audio: Rain, LoFi, White Noise, Forest, Chime, Soft and Deep Focus.
- Audio loops while a focus session is running and stops when the session stops.
- Focus sessions are saved by date and appear in Calendar.
- Task reminders with selectable notification sounds.
- Habit tracking with per-day percentage completion (0–100%).
- Journal with default learning/feeling/plan prompts, custom sections, date/time history and image attachments.
- Full calendar month navigation and selected-day analysis: focus, sessions, completed/open tasks, habit percentages and journal/learning content.
- AI coach screen for detailed day analysis using focus/tasks/habits/journal data.
- AI image analysis for a chosen study/work image.
- Focus Room with camera on/off and mute UI. Multiplayer Join is intentionally UI-only and not implemented.
- App blocking through Android Accessibility Service.
- App usage list through Android Usage Access.
- Settings for AI, focus defaults, app blocking/usage, permissions and section styling.
- Custom Luma launcher icon.

## Important Android limitations
Some capabilities require the user to grant Android permissions manually:
- Notifications
- Camera
- Accessibility Service (app blocking)
- Usage Access (app usage)
- Exact alarms (task reminders)

AI requires the user's own Anthropic API key in Settings. Luma does not include a shared key.
